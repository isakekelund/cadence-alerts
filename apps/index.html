Full screen, without Safari's bars

A profile adds the apps as full-screen web clips with the same icons. It holds only the ten names, addresses and icons.

  1. Tap a link below and choose Allow.
  2. Open Settings, tap Profile Downloaded, then Install. iPhone says the profile is not signed; that is expected for one you made yourself.
  3. The first time you open each app, sign in to Claude in it.
